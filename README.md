#GITREKT CODING CHALLENGE#

In this repository you can find the documentation for the challenge. It is still WIP and currently consists of 5 levels. The project is self-hosted and everything 
except for the pictures (due to copyright reasons) is done without the help of AI. 

This project is a collection of logic and cryptography-based challenges designed to test pattern recognition, logical reasoning, visual analysis, and problem-solving skills.

The challenges include:

Number Sequence Analysis – Identify patterns and underlying rules within numerical sequences and determine the missing or subsequent values.
Hidden Messages in Images – Analyze images to discover concealed information, messages, or patterns.
Basic Cryptography – Decode and interpret messages using fundamental cryptographic techniques and classical ciphers.
