About this project

This project is designed to give you the opportunity to explore some mathematical concepts beyond school. The tasks are structured so that you first need to understand the problem, and then use Python scripts to find a solution. Once you'solved a problem change the URL (according to your solution), which will hopefully reveal the next level. In each level, you will have the option to view our solution beforehand. We provide detailed explanations for every problem to ensure you fully understand it. You can access the solution page by adding _solution to the current webpage URL (e.g., math-challenge_solution.html). Make sure to occasionally check the HTML code of the website, as it may contain helpful hints. :) We're both still students currently visiting grade 12 and the whole project is still WIP. If you have any suggestions for further levels you can write to gitrekt.coding.challenge@gmail.com Thank you for visiting website and we wish you the best of luck !!!

The challenge currently consists of 5 levels and there is NO reward at the end.
